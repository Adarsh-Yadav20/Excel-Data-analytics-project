# Excel Data Analytics Project

## 📊 Project Overview
This project focuses on analyzing business sales and performance data using Microsoft Excel.

## 🛠️ Tools & Skills Used
- Microsoft Excel
- Data Cleaning
- Excel Formulas & Functions
- Data Analysis
- Conditional Formatting
- Pivot Tables
- Charts & Dashboard

## 🧹 Data Cleaning
The dataset was prepared and cleaned to make the data suitable for analysis. This included checking data consistency, formatting, and organizing the required fields.

## 📈 Analysis
Excel formulas, functions, and analytical techniques were used to analyze business performance and identify useful patterns in the data.

## 📊 Dashboard
An interactive Excel dashboard was created to present important business performance metrics and make the analysis easier to understand.

## 🔍 Key Learning
Through this project, I practiced data cleaning, Excel formulas, data analysis, visualization, and dashboard creation.
